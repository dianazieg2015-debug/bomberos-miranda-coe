# ¡Bienvenido/a al proyecto!

Gracias por aceptar la invitación al **Sistema de Gestión Operativa COE · Bomberos Miranda**.

## Dónde está la app (APK)

La aplicación Android está dentro de este repositorio, en la carpeta **`apk`**:

```
apk/BomberosMiranda-COE.apk
```

- **Para verla en GitHub:** https://github.com/dianazieg2015-debug/bomberos-miranda-coe/blob/main/apk/BomberosMiranda-COE.apk
- **Para descargarla directo:** https://github.com/dianazieg2015-debug/bomberos-miranda-coe/raw/main/apk/BomberosMiranda-COE.apk

### Cómo instalarla en el teléfono

1. Descarga el archivo `BomberosMiranda-COE.apk` en un teléfono Android.
2. Ábrelo. Si Android lo pide, permite **instalar aplicaciones de origen desconocido** para tu navegador o tu gestor de archivos.
3. Para entrar necesitas un **usuario y una contraseña temporal**: pídeselos a Diana. Al entrar por primera vez, la app te pedirá crear tu propia contraseña.

## Cómo está organizado el proyecto

| Carpeta | Qué contiene |
|---|---|
| `apk/` | La app lista para instalar |
| `AndroidStudioProjects/Bomberoscuartelcentral/` | El código de la app Android (Kotlin) |
| `AndroidStudioProjects/BomberosCOEWeb/` | El código del panel web del COE (React) |
| `supabase/` | La base de datos y sus reglas de seguridad |

El [README](README.md) explica cómo poner en marcha cada parte.
